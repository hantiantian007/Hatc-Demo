【需求文档】客户留资三期

列表原型 详情原型 返回需求看板

本期在“客户留资二期”基础上继续做减法与细化，重点统一列表字段命名、补充销售录入字段、增强线索详情的可维护能力，并将部分历史只读字段改为可修正。

1. 本期范围
模块 调整方向 备注
留资列表 新增留资次数、优化客户来源字段展示、补充提示说明。 主要涉及列表表头、表格字段命名及查看效率。
销售录入弹窗 增加其他联系方式，调整字段取舍，保留轻量录入逻辑。 聚焦轻量录入和必要信息补充。
线索详情 增强基础信息维护能力、展示留资记录数量、支持状态和关联账户再次修改。 让销售在详情页内完成更多纠偏动作。
2. 留资列表调整
字段 / 交互 调整后口径 业务规则
留资次数 列表内增加 留资次数。 表示同一客户在留资系统中的累计留资次数，按客户唯一标识聚合统计，用于识别重复留资客户。
客户来源 列表字段页面来源字段名称统一为 客户来源。 枚举值统一为：销售录入、官网录入、注册页录入。
客户来源提示 在列表表头“客户来源”旁增加提示 icon。 鼠标移入 icon 时展示提示语：客户来源代表客户从哪里输入的留资信息。
线索热度 改为 非必填。 未评估时显示为 --；录入或跟进时允许选择“暂不评估”。
3. 销售录入弹窗调整
字段 / 区域 调整后口径 业务规则
弹窗名称 按钮与弹窗标题统一调整为 销售录入。 不再使用“新增线下线索”命名。
其他联系方式 在基础信息区新增文本输入框。 选填，用于补充手机号、邮箱、微信 / WhatsApp 之外的其他联系信息，最长 100 字符。
线索热度 保留高 / 中 / 低，同时增加“暂不评估”。 默认不强制要求销售在录入时完成热度判断。
4. 线索详情调整
模块 调整后口径 业务规则
基础信息 取消“国家 / 地区”字段，增加可编辑的 咨询内容、信息来源。 销售可在详情页内修正客户录入时填写的信息，保存后按最新值生效。
查询渠道 新增可编辑下拉字段。 枚举值固定为：WhatsApp、Email、Zendesk、Telegram。
留资记录 Tab Tab 名称需带数量，例如 留资记录（3）。 用于让销售快速感知该客户的历史留资频次。
关联账户 由“仅支持新增关联”调整为 支持修改关联。 若已有绑定关系，也需提供修改关联入口，并记录变更日志。
跟进状态 即便当前已是“已转化”或“无效线索”，仍允许再次修改。 系统需保留完整状态变更轨迹，不得覆盖历史。
5. 验收标准
验收项 通过标准
列表表头由“提交次数”改为“留资次数”。 页面与 PRD 文案一致，不再出现“提交次数”。
客户来源表头存在提示 icon。 鼠标移入时可见提示语“客户来源代表客户从哪里输入的留资信息”。
销售录入弹窗包含“其他联系方式”。 该字段在弹窗中可录入。
线索详情基础信息存在咨询内容、信息来源、查询渠道。 三个字段均可在详情页内维护并保存。
留资记录 Tab 带数量展示。 例如显示为“留资记录（3）”。
已转化 / 无效线索支持再次修改状态，关联账户支持修改。 页面上存在对应入口与文案说明。
