后台商品管理列表 (admin-product-management.html)

2026-07-01 产品部 V2.2.0
1. 顶部全局操作与筛选
UI 元素 数据来源与状态 交互方式与信息处理逻辑
新增商品按钮 页面右上角全局入口。 交互：点击跳转至 admin-product-edit.html。
参数传递：不携带任何参数，代表进入全新的空表单初始化模式。
商品状态筛选 来源：固定枚举。
状态：下拉单选框。		 包含值：全部状态（默认）、已上架、已下架、定时上架。
交互：选中某一项后，立即触发 Ajax 接口请求，携带 status 参数重新加载下方表格数据。
商品类型筛选 来源：固定枚举。
状态：下拉单选框。		 包含值：全部类型（默认）、虚拟商品、实体商品。
交互：选中某一项后，携带 type 参数重新加载下方表格数据。
2. 表格数据列展示规范
列名称 数据来源与计算方式 排列展示与处理逻辑
商品信息 来源：商品基础表 (Product Base)。 排列：左侧展示商品图标 Icon (60x60缩略图)；右侧分两行，上行为粗体商品名称，下行为浅色唯一商品 ID (如 PRD-001)。
商品类型 来源：新增商品时的选择。 排列：上方以 Badge 形式展示“虚拟商品”或“实体商品”；下方固定展示绿色字体的“ 余额购买”支付方式标签。
售价 来源：商品关联的套餐配置表。
计算方式：遍历该商品下所有套餐，取出金额最小值。 		处理逻辑：
1. 若只有 1 个套餐，直接展示金额（如 $500.00）。
2. 若存在多个套餐，展示格式为“最低价 起” (如 $100.00 起)。
交互：对于多套餐，鼠标悬浮在金额上时，唤起 Tooltip 悬浮卡片，卡片内垂直排列展示所有套餐的详细明细（套餐名称、原价、现价、独立库存）。
库存 / 销量 来源：订单及库存系统。
计算方式：该商品所有套餐的库存之和 / 该商品所有套餐的历史累计销量之和。 		排列：为节省横向空间，采用上下两行布局。上行显示“库存: 100”，下行显示“销量: 50”。
浏览数据 来源：客户端埋点统计系统。 排列：上下两行布局。
上行展示 PV (浏览量)：累计被打开的次数。
下行展示 UV (访客数)：累计查看过该商品的独立用户数。
状态 来源：商品基础表的上架状态。 处理逻辑：
1. 已上架：绿色 Badge。
2. 已下架：灰色 Badge。
3. 定时上架：橙色 Badge。下方需额外增加一行小字，显示配置的具体生效时间（如 2026-07-02 10:00）。
3. 行级操作与流转机制
操作按钮 动作类型 交互流转与跳转参数
编辑 页面跳转。 交互：点击跳转至 admin-product-edit.html。
参数传递：URL 必须携带当前点击商品的 ID（例如：admin-product-edit.html?id=PRD-001）。编辑页面将根据该参数请求详情接口，实现数据的完整回显。
下架 / 上架 状态反转调用。 交互：
1. 若当前为上架，按钮显示为“下架”；反之显示为“上架”。
2. 点击后无需二次确认弹窗，直接调用后端状态更新接口。按钮呈现 Loading，成功后局部刷新该行状态，并弹出“操作成功” Toast。
删除 高危数据清除。 交互：
1. 点击后屏幕居中弹出二次确认弹窗（“确定要删除该商品吗？此操作不可恢复”）。
2. 确认后调用删除接口，成功后从表格中移除该行，并弹出“删除成功” Toast。
4. 逆向与异常流转处理
异常场景分类 触发条件与场景描述 前端处理方案与交互阻断
删除业务约束 用户尝试点击删除一个处于“已上架”或“定时上架”状态的商品。 强阻断：上架状态下的商品严禁直接删除。前端需将该行的“删除”按钮置灰（Disabled）并显示为 not-allowed，或者在点击时拦截并 Toast 提示：“请先下架该商品后再进行删除操作”。
状态切换异常 用户点击“上架/下架”，但由于网络波动或后端并发校验失败（如库存不足导致无法上架），接口报错。 状态回滚：前端不应做盲目的乐观更新。按钮展示 Loading 时锁定点击，若接口明确返回失败或超时，按钮恢复原状态，原列表状态字段不变，并弹出红色 Toast 提示失败原因（如“库存不足，无法上架”）。
无数据与搜索落空 当前系统内无商品，或通过“商品状态”、“商品类型”组合筛选后，未匹配到任何商品。 空状态占位：隐藏表格的空白数据行，在表格区域居中展示“暂无数据”的视觉插画及提示文案。若为筛选落空导致，需额外提供一个“清空筛选条件”的文字按钮，点击后一键重置筛选并重新请求列表。
列表加载崩溃 进入列表页时，获取列表数据的 API 请求超时或返回 500。 异常降级：结束骨架屏或 Loading 动画，显示“数据加载失败，请检查网络”的提示，并提供“点击重试”按钮，防止页面出现无休止的白屏死锁。
