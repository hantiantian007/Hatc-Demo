需求规格说明书 (PRD)

极度盲托模式与混合账户隔离规则 (基于 Group)

2026-06-24 产品部 V1.2.0

1. 业务背景与核心原则

平台推出“星启先锋一号”等全托管代购/理财服务。为了防止客户因盘中交易回撤产生恐慌和客诉，必须对参与托管的 MT5 账户实施**“极度盲托”**的数据屏蔽（即不展示余额、净值、不提供出金按钮，仅允许入金和申请解除委托）。

【最高原则】：数据隔离必须精确到 MT5 账号维度。同一个用户如果同时拥有“标准账户”和“托管账户”，标准账户的所有数据和功能必须保持 100% 正常，绝不允许一刀切式的用户级屏蔽。

2. 判定依据 (唯一事实来源)

判断一个账户是否为“托管账户”，不依赖 CRM 本地数据库的手动状态，而是严格基于 MT5 Server 接口返回的 Group (分组) 字段进行判断。

  • 系统需维护一个“托管分组正则匹配列表”或“枚举列表”（例如：.*-PAMM-.* 或具体的 Live-PAMM-A1）。
  • 当通过 API 实时获取账户列表时，只要 MT 账号的 Group 命中该列表，前端/后端立刻触发“盲托屏蔽规则”。
  • 若用户申请解除委托，后台将其 MT 账号转出该分组，前端无需额外操作，自动恢复标准展示。

3. 前端 UI 屏蔽规则 (客户视角)

3.1 客户端“我的账户”列表

功能/字段 标准账户 (未命中托管组) 托管账户 (命中托管组)
余额 (Balance) 正常展示 强制展示为 `***`
净值 (Equity) 正常展示 强制展示为 `***`
可用预付款 / 杠杆 正常展示 DOM 节点隐藏
操作按钮 入金、出金、内部转账、修改密码 仅保留“追加资金(入金)”和“申请解除委托”。隐藏出金、转账、改密。
状态标识 正常交易 带锁 Icon 的“委托交易中”

3.2 全局查询与报表隔离

  • 总资产计算：页面顶部“总资产”计算时，必须 exclude (排除) 托管账户的余额，并附带问号提示：“仅包含标准账户资产，不含托管账户”。
  • 报表查询下拉框：在【我的持仓】、【平仓交易记录】页面的“请选择 MT 账号”下拉框中，托管账户所在选项必须被剔除或隐藏，禁止用户选择托管账户查询明细。
  • 内部转账 (内转)：作为“转入方”，托管账户可选（等同于追加投资）；作为“转出方”，托管账户必须在下拉框中置灰或隐藏，禁止转移资金。

4. 后端 API 拦截规则 (安全兜底)

即使前端做了隐藏，后端接口必须同步进行安全校验，防止用户通过抓包工具篡改请求。

  • 交易流水接口拦截：当请求 /api/trades/history 等明细接口时，若传入的 account_id 所属 Group 命中托管组，后端强制抛出 403 Forbidden: 托管账户不支持查询明细。
  • 资金转出拦截：当请求出金或转账接口时，若源账户为托管组账户，后端拦截并返回业务错误。
  • 密码接口拦截：禁止通过 API 对托管组账户重置主密码或观摩密码。
