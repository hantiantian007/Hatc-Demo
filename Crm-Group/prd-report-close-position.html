本次迭代核心调整 (面向产研测)

  • 报表更名：全局原“平仓统计”统一更名为“平仓交易记录”。
  • 数据范围限定：明确仅统计并展示已平仓订单，不再包含未平仓的持仓数据。
  • 移除无关字段：为保持版面简洁，去除了搜索条件及表格中的“客户邮箱”栏位；去除了“交易奖励（佣金）”栏位（佣金数据由单独的佣金报表负责）。
  • 字段更名与枚举修改：表格及汇总中的“利润($)”统一更名为“盈亏($)”；买卖类型枚举值由“卖出交易/买入交易”更正为“卖出/SELL”和“买入/BUY”。
  • 新增计算字段：表格中新增“持仓时间”字段，由开仓至平仓的时间差计算得出，方便客户/代理知悉交易操作时长。
  • 字段顺序调整：表格列顺序调整，交换了盈亏和手续费的位置（当前顺序：持仓时间 -> 手续费($) -> 库存费($) -> 盈亏($)）。
  • UI与交互优化：表格数据及表头统一设置为水平居中对齐，并增加单元格边框；表格底部补充标准的翻页组件（分页符）。

一、需求概述

1.1 业务背景： 提供所有已平仓订单的明细查询及多维度的汇总统计（盈亏、手续费等），满足业务人员及代理对名下客户或全局客户的平仓数据追溯需求，同时计算开仓至平仓的时间差，方便了解交易操作时长。

1.2 核心说明： 以底层 MT5 为唯一数据源（SSOT）。仅取有关交易账号的平仓交易记录。报表中不包含佣金数据，佣金明细由“佣金报表”负责。

1.3 数据过滤约束： 平仓交易记录表内，仅统计并展示已平仓订单，所有尚未平仓的持仓订单不在此报表中展示。

二、页面布局与搜索过滤条件

页面顶部为多维度的组合搜索区域，支持以下筛选条件（各条件为并集 AND 关系）：

字段名称 控件类型 规则描述与说明
MT账号文本输入框 精确/模糊匹配（视底层架构而定，建议支持精确查询），限制输入不超过 50 字符。
客户姓名文本输入框 模糊匹配客户姓名，限制不超过 50 字符。
持仓编号文本输入框 根据 MT5 底层 Position ID 精确查询。
交易品种下拉单选 来源于 MT5 配置的所有可用交易品种。默认选中“全部”。
买卖类型下拉单选 固定选项：全部、买入/BUY、卖出/SELL。默认选中“全部”。
订单编号文本输入框 根据 MT5 底层 Order ID 精确查询。
开仓日期双日期选择器 选择开始日期至结束日期，筛选订单的开仓时间（非平仓时间）。
关系树查询下拉单选/级联选择 用于按代理层级过滤其下级挂载的客户数据，仅展示登录账号有权限查看的节点。

注： 不包含“客户邮箱”的搜索条件。

操作按钮：

  • 搜索： 点击后根据上述条件请求接口，刷新表格及汇总统计数据。
  • 重置： 清空所有搜索条件至默认状态。
  • 报表导出： 将当前筛选条件下的所有分页数据导出为 Excel 或 CSV 格式。

三、汇总统计规则

在数据表格上方展示当前筛选条件下的汇总结果，数据随搜索条件动态更新：

  • 交易手数总计(手)： 当前列表所有平仓订单的 交易手数 字段总和。
  • 盈亏总计($)： 当前列表所有平仓订单的 盈亏 字段总和（MT5底层平仓利润）。保留两位小数。
  • 库存费总计($)： 当前列表所有平仓订单的 库存费 字段总和（Swap）。保留两位小数。
  • 手续费总计($)： 当前列表所有平仓订单的 手续费 字段总和（Commission）。保留两位小数。

四、数据表格字段说明

表格数据必须与高保真原型 100% 对齐，所有单元格需居中对齐展示。包含底部标准分页组件（默认每页 20 条，可选 10/20/50 条）。

字段名称 数据来源及显示规则
客户姓名注册开户时的全名。
MT账号客户在 MT5 开通的交易账号。
订单编号MT5 交易底层返回的 Order ID。
持仓编号MT5 交易底层返回的 Position ID。
开仓时间该笔订单的开仓时间，格式：YYYY-MM-DD HH:mm:ss。
交易品种如 XAUUSD 等。
买卖类型枚举值：买入/BUY 或 卖出/SELL。
交易手数订单的交易体量（Lots）。
开仓价格MT5 底层的建仓价格（Price Open）。
平仓时间订单的平仓时间，格式：YYYY-MM-DD HH:mm:ss。若为未平仓的异常冗余记录（不应出现在此表，理论上只有已平仓订单）则显示 -。
平仓价格MT5 底层的平仓价格（Price Close）。
持仓时间前端或后端计算得出：平仓时间 - 开仓时间。显示格式例如：5小时0分钟59秒、12分钟30秒、45秒。若缺乏时间则显示 -。
手续费($)MT5 底层返回的订单手续费（Commission）。
库存费($)MT5 底层返回的隔夜利息/库存费（Swap）。
盈亏($)MT5 底层返回的平仓利润（Profit）。正数不带加号，负数带减号。
注释MT5 底层附带的订单 Comment，例如 [tp 4171.85] 等，若无则为空或 -。

五、业务交互联动与异常说明

  • 唯一数据源： 数据必须来源于 MT5 底层的结算平仓记录，系统自身不产生任何基础交易记录。
  • 权限隔离： 根据登录人员的角色（管理员、IB代理、销售），底层接口自动根据通用权限模块进行数据范围过滤。例如 IB 仅能查询到其关系树下级的平仓数据。
  • 分页逻辑： 表格底部分页组件切换条数或点击上下页时，前端向后端请求对应 `page` 和 `size` 的数据进行刷新，同时保留当前的搜索过滤条件。
