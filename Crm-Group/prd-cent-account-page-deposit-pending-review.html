【页面 PRD】待审核入金

本文档仅描述 待审核入金页面 因接入美分账户而新增或调整的需求。
1. 页面目标
目标在后台待审核入金页面中补齐美分账户审核识别能力，便于审核员在入金审核阶段明确区分 标准账户 与 美分账户，同时查看对应原始入金金额与账户余额口径。
涉及页面admin-deposit-pending-review.html
2. 新增/调整需求
需求项说明
搜索区新增 MT类型搜索区需新增 MT类型 筛选，支持按 标准账户、美分账户 查询待审核入金记录。
列表新增 MT类型识别列表中需单独展示 MT类型 字段，通过胶囊样式醒目标记 标准账户 与 美分账户。
金额改为复合展示列表中的 金额 列采用复合展示：第一行展示 入金金额，标准账户按 USD 展示，美分账户按 USC/美分 展示；第二行展示 支付金额，标准账户可直接展示 USD，人民币通道展示 CNY。
明细展示金额拆分展开详情中需拆开展示 入金金额、原始入金金额、汇率、支付金额、账户余额、账户净值、可用保证金 等字段；美分账户的 入金金额 与 原始入金金额 使用 USC/美分 展示。
展开明细样式展开详情需采用垂直列表样式：左侧为字段名，右侧为值，行间保留分隔线，操作按钮放在末行，避免块状卡片导致信息分散。
汇总增加美分辅助口径页头汇总除展示统一 USD 金额外，可额外展示 美分原始金额(USC) 辅助值，用于帮助后台快速了解当前美分审核规模。
审核状态保持原样本次改造不调整现有 审核状态 列的文案、位置或展示逻辑，仅补充美分账户相关识别与金额信息。
布局兼容性因列表字段较多，页面需采用横向滚动方案承载内容，避免固定列宽导致文案挤压错位。
3. 数据口径
单位规则入金金额 需跟随账户类型展示，标准账户显示 USD，美分账户显示 USC/美分；人民币通道需补充 CNY 支付金额及汇率。
展示原则后台审核页面需优先保证审核员识别效率，因此美分账户记录必须可被一眼区分，避免与标准账户混淆。
4. 测试重点
1. MT类型筛选是否支持标准账户 / 美分账户。
2. 列表中是否能正确区分标准账户与美分账户。
3. 列表金额列是否已改为复合展示，且不再展示“实际支付金额”。
4. 美分账户记录是否展示原始入金金额(USC)，人民币通道是否展示支付金额与汇率。
5. 展开详情是否已改为垂直列表样式，且金额字段已拆分展示。
6. 审核状态列是否保持原样，未被本次改造影响。
7. 字段较多时页面是否可通过横向滚动正常浏览。
