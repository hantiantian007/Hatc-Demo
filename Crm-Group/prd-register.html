【需求文档】Crm-Group 注册页面

返回高保真原型 返回需求看板

本期需求重点 (致产研测)

  • 增加客户留资入口： 本次版本主要在原有注册流程基础上，仅新增了针对无推荐码客户的“留资入口”（即点击申请账号弹出的收集表单），其他注册逻辑保持不变。
  • 留资表单新增字段： 在留资申请表单中，新增必填字段“信息来源”，选项包含：“媒体”、“线下”。该字段位置位于电子邮箱正下方。

1. 业务说明

1. 本页面为 Crm-Group 的前端客户注册页面，采用暗黑高级风格。

2. 强绑定逻辑：用户注册必须填写推荐码（绑定上级代理/推荐人）。若无推荐码，需通过“申请账号”进入留资流程，由后台市场人员介入分配。

2. 字段交互限制

字段名称 是否必填 限制规则 逻辑说明
邮箱 是 标准邮箱格式 输入失去焦点时校验，若格式错误或为空，输入框标红并底部提示“请输入有效的邮箱地址”。
密码 是 8-20位，含字母和数字 提供明文/密文切换（眼睛图标）。不符合复杂度要求时提示错误。
推荐码 否 英数字组合 下方增加文案“无邀请码，请点击此处：申请账号”。
“申请账号”四字为品牌黄色且支持点击，点击后弹出【试用账户申请】表单弹窗。
验证码 是 4位图形验证码 点击图片可刷新。输入错误提示“验证码错误”。
注册条款 是 默认勾选 必须勾选才可提交。若未勾选点击提交，则提示“请阅读并同意注册条款”。

3. 提交逻辑

1. 点击“提交注册”时，校验所有必填项及格式。

2. 校验通过后，调用注册接口。成功则跳转至登录页或直接登录进入系统。

3. 失败则在对应字段下方飘红提示具体的错误原因（如：该邮箱已被注册、推荐码无效等）。

4. 【留下资料】留资弹窗

1. 点击“无邀请码，请点击此处：申请账号”触发弹窗。

2. 弹窗文案提示：“信息提交后，我们的顾问会在2个工作日内与您联系”。

3. 成功提交后关闭当前弹窗，弹出新的提示窗：“您的资料已提交，请注意邮箱信息”。

字段名称 是否必填 限制规则 逻辑说明
姓名 是 无 标准文本输入框。
联系电话 是 仅限数字 输入失去焦点时校验，不允许输入非数字字符。
电子邮箱 是 标准邮箱格式 失去焦点时校验邮箱格式。
信息来源 是 ["请选择", "媒体", "线下"] 下拉单选框，提交时若未选择则提示必填。
咨询内容 否 ["请选择", "成为代理", "政策了解", "个人交易", "其他"] 下拉单选框。
微信 否 文本输入框 非必填。
WhatsApp 否 文本输入框 非必填。
其他联系方式 否 文本输入框 非必填。
验证码 是 4位英数混合图形验证码 点击图片可刷新。
取消/提交按钮 - - 点击【提交】后校验必填项，校验通过后弹出成功提示：“您的资料已提交，请注意邮箱信息”，并将留资数据写入 Crm-Group 后台留资列表。
