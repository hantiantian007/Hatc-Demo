1. 需求目标

业务目标：客户名下可能存在多个 MT 账号，但仅有其中一个为委托交易账号。客户先正常注册 CRM 账户并开通 MT5 账号，后续当 MT5 账号被切入委托组/托管组时才进入委托限制态。限制态下需同步受到禁内转、禁密码修改/重置、按规则开放交易数据查看三类限制；CRM 仅负责识别、展示与规则配置，客户实际查看动作在 MT5 系统 内完成。

模块 交互与显示规则 业务口径
承载页面 新增独立的委托交易账户管理页与规则配置页。 委托交易账户管理页负责账号识别、限制状态、开放时间与结束状态管理；规则配置页负责按组/按 MT 账号配置查看开放规则。
本期边界 本期 CRM 仅做记录、识别、限制展示、规则配置，不在 CRM 内承接“查看数据”的实际入口。 客户是否能看到数据，由 MT5 侧根据规则开关/定时结果处理；CRM 只展示当前规则结果与来源。
委托分组配置 委托分组通过后台配置维护，可随时新增或删除。 MT5 账号命中任一委托分组即进入委托限制态；移出所有委托分组后视为委托结束并恢复普通能力。

2. 委托交易流程

步骤 流程说明 业务口径
1. 正常开户 用户正常注册 CRM 账户，并通过 CRM 开通 MT5 账号。 该阶段 MT5 账号为普通交易账号，不自动带入委托限制。
2. 初始分组 MT5 账号开通时，可属于任意分组。 开通时是否属于普通组、测试组或其他交易组，不影响后续是否能进入委托态。
3. 转入委托组 当 MT5 账号被转移至任一委托交易分组后，系统开始对该账号施加委托限制。 “切入委托分组”是委托限制的正式触发点，而不是账号开通时间；系统需记录移入委托组时间。
4. 限制生效 限制期间，用户默认不能看见持仓、交易、平仓记录等交易相关数据。 限制范围仅针对交易数据可见性；资金相关能力中保留出入金，禁用内转。
5. 按规则开放 到达后台配置的指定时间后，用户可在 MT5 中查看持仓、交易和平仓记录等交易数据。 开放时间由后台规则控制，可为手动开启或自动定时开启。

3. 委托账号识别规则

规则项 规则描述 说明
识别方式 委托交易账号按MT 分组识别，不由后台人工逐个指定。 后台维护一套“委托交易分组名单”。客户名下 MT 账号命中任一委托分组时，系统自动标记为“委托账号”。
单客户多账号 一个客户可有多个 MT 账号，但同一客户同一时点仅应识别出一个有效委托账号。 若客户名下多个账号同时命中委托分组，属于异常数据，后台需按异常状态高亮提示，便于人工核查。
未命中场景 客户名下账号均未命中委托分组时，账号列表不展示“委托账号”标签。 该客户视为普通客户，无需展示委托开放规则。
识别结果展示 账号列表新增“账号用途”字段，枚举值为：委托账号、普通账号、异常。 委托账号：命中委托分组且唯一。
普通账号：未命中委托分组。
异常：同一客户命中多个委托账号或缺少必要规则配置。

4. 托管组限制规则

规则项 交互与显示规则 业务口径
内转限制 命中托管组的委托账号不支持内转。 仅当委托结束，账号从托管组切换到非托管组后，才恢复内转能力。
出入金能力 命中托管组的委托账号支持出入金。 委托限制不影响正常入金、出金；仅限制内转能力，不限制资金进出。
密码限制 命中托管组的委托账号不支持在 CRM 系统内修改或重置 MT5 账号密码。 托管中禁止通过 CRM 触发 MT5 密码修改或密码重置；脱离托管组后恢复正常能力。
能力恢复 委托结束后，需先将账号切换到非托管组，再恢复受限能力。 恢复能力的前置条件不是“委托结束”状态本身，而是账号已不在托管组中。
CRM 职责 CRM 仅展示当前是否受限，不在 CRM 中提供“强制内转”“强制重置密码”等例外入口。 避免后台人员绕开托管限制，保持限制口径一致。

5. 查看数据开放规则

规则项 交互与显示规则 业务口径
查看入口 客户查看数据的实际入口在MT5 系统，CRM 不承接查看动作。 CRM 只负责展示“当前能否查看”的规则结果，以及该结果来源于哪条规则。
开启方式 查看数据支持两种开启方式：手动开关、按月定时自动开启。 同一条规则仅选择一种主模式；如为手动开关，则由运营手工控制开/关；如为自动开启，则按配置时间自动生效。
配置粒度 规则支持按某个组或某个 MT 账号配置。 优先级为：MT账号规则 > 分组规则。当账号命中个人规则时，优先使用个人规则，不再回退组规则。
自动开启周期 自动开启支持三种时间模式：每月固定时间、每周固定时间、每月内指定时间。 每月固定时间：例如每月 15 日 00:00 - 23:59。
每周固定时间：例如每周三 09:00 - 18:00。
每月内指定时间：例如每月第 1/3/5/20 日的指定时间段。
开放时间 规则需明确“什么时间开放查看数据”，至少包含：开始时间、结束时间，或按月固定的开放日/开放时段。 当当前时间落在开放窗口内时，状态为“开放中”；否则为“未开放”。
数据范围 开放规则控制的数据范围包括：持仓、交易、平仓记录等交易相关数据。 未开放时，上述交易数据均不可见；开放后由 MT5 侧统一放开查看。
CRM 范围 本期规则控制的是“是否允许在 MT5 查看交易数据”，不扩展到 CRM 内部报表开放。 用户能否看到数据由 MT5 侧消费规则结果执行。

6. 委托结束 / 移出委托组

规则项 交互与显示规则 业务口径
结束触发点 委托结束的系统判定触发点为：MT5 账号被移出委托组。 仅有“口头结束”“业务确认结束”但账号仍在委托组中时，系统仍视为委托中；系统需记录移出委托组时间。
恢复顺序 账号移出委托组后，系统解除委托限制并恢复普通账号能力。 恢复内容包括：恢复内转、恢复 CRM 内 MT5 密码修改/重置、恢复交易数据常态可见。
规则失效 账号移出委托组后，不再命中委托查看规则。 委托交易账户管理页中可展示为“已结束”或进入历史记录；客户详情页不做委托信息展示。
历史追溯 委托结束后，建议保留一条“曾为委托账号”的变更记录。 便于运营、客服、风控追溯该账号何时移入委托组、何时移出委托组。
异常场景 若业务声称委托结束，但账号仍在委托组，则继续按委托中处理。 分组结果优先于人工口径，避免系统状态与业务口径不一致。

7. 规则配置页

模块 交互与显示规则 说明
规则列表 列表至少展示：规则名称、作用范围、目标对象、开启模式、开放数据、开放时间、当前状态、优先级、最近更新时间。 便于运营快速核查某个组/某个 MT 账号当前到底受哪条规则控制。
新建规则 支持选择按组配置或按 MT 账号配置，并设置手动开关或定时自动开启。 目标对象支持单选；若按组配置，输入组名；若按账号配置，输入 MT 账号。
开放数据 规则需明确开放的数据范围，默认包括持仓、交易、平仓记录。 本期按整组交易数据统一开放，不拆分成单独子权限。
时间配置 支持配置每月固定时间、每周固定时间、每月内指定时间三种时间模式。 用于表达“每月什么时候开放查看数据”或“每周什么时候开放查看数据”的业务要求。
委托分组配置 新增独立的“委托交易分组配置”页面，用于维护委托分组名单，支持新增、编辑、删除与启停用。 分组配置变更将影响后续识别逻辑；删除分组需谨慎，避免导致委托识别范围变化。
生效结果 保存后生成规则结果，供 CRM 展示与 MT5 侧消费。 规则保存成功不等于用户已查看，仅表示查看权限在该时间窗内可开启。

8. 委托交易账户管理页

改动位置 显示字段 说明
管理列表表格 在现有账号列表中新增：账号用途、查看方式、查看状态、规则来源、开放时间、委托状态、移入委托组时间、移出委托组时间。 独立集中展示委托账号与已结束委托账号；普通客户详情页不展示这些管控字段。
时间字段口径 “移入委托组时间”取 MT5 账号最近一次进入委托分组的时间；“移出委托组时间”取最近一次离开委托分组的时间。 若账号当前仍在委托中，则“移出委托组时间”显示 --。
委托账号标识 委托账号以金棕色标签高亮展示，文案为“委托账号”。 颜色与现有品牌强调色保持一致，便于在管理页中快速识别。
查看方式文案 固定展示为MT5 查看。 明确告诉后台：CRM 不处理查看动作，仅做规则透传与核查。
查看状态文案 客户可见字段展示枚举：未开放、开放中、手动开启、异常。 异常用于承载规则缺失、多个规则冲突或命中多个委托账号等场景。
委托状态文案 展示枚举：委托中、已结束、异常。 委托中以“仍在委托组”为准；移出委托组后展示已结束。
客户详情页 客户详情页不新增任何委托交易管理字段。 客户详情仅显示原本信息，不承接委托识别、规则展示和结束状态展示。

9. 字段定义

字段名 类型 枚举/示例 说明
isEntrustedAccount Boolean true / false 是否为委托交易账号，来源于 MT 分组识别结果。
accountUsage String 委托账号 / 普通账号 / 异常 账号用途展示文案。
visibilityStatus String 未开放 / 开放中 / 手动开启 / 异常 客户当前是否可在 MT5 中查看该委托账号数据。
transferRestricted Boolean true / false 是否处于禁内转状态；命中托管组时为 true。
depositWithdrawAllowed Boolean true / false 是否允许出入金；委托账号在限制期间仍为 true。
passwordResetRestricted Boolean true / false 是否处于禁密码重置状态；命中托管组时为 true。
passwordModifyRestricted Boolean true / false 是否处于禁密码修改状态；命中托管组时为 true。
viewChannel String MT5 客户查看数据的承载系统。
visibleDataScope String 持仓 / 交易 / 平仓记录 规则控制的交易数据范围。
ruleMode String 手动开关 / 自动定时 查看权限的开启模式。
scheduleType String monthly_fixed / weekly_fixed / monthly_custom 自动开启的时间模式类型，分别对应每月固定时间、每周固定时间、每月内指定时间。
ruleScope String 按组 / 按MT账号 规则配置粒度。
ruleSource String 组规则 real\Trust\Managed\Main 当前账号所命中的规则来源，用于后台核查。
openStartAt Datetime 2026-08-15 00:00:00 当前规则的开放开始时间。
openEndAt Datetime 2026-08-15 23:59:59 当前规则的开放结束时间。
entrustStatus String 委托中 / 已结束 / 异常 当前委托状态，是否仍受委托限制。
movedIntoTrustGroupAt Datetime 2026-07-01 10:21:08 最近一次移入委托组时间；用于判断该轮委托是什么时候开始的。
movedOutOfTrustGroupAt Datetime 2026-08-21 12:00:00 最近一次移出委托组时间；仍在委托中时显示 --。

10. 异常与边界

场景 处理规则 说明
多个账号命中委托分组 账号用途统一标为异常，客户可见状态也显示异常。 提示后台先修正规则，不允许默认任选其一作为委托账号。
开放日未配置 客户可见状态显示异常，规则来源、开放时间均显示 --。 便于后台快速发现配置缺失。
非委托账号 客户可见相关字段全部显示 --。 避免普通账号误被解释为也受开放规则限制。
组规则与账号规则同时命中 优先采用MT账号规则，委托交易账户管理页需展示实际命中的规则来源。 保证规则优先级明确，避免同一账号被多条规则重复解释。
委托结束但仍在托管组 仍视为受限状态，继续禁内转、禁密码重置，并沿用查看规则。 必须先切换到非托管组，相关限制才解除。
