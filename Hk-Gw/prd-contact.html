【需求文档】Hk-Gw 官网留资入口

返回高保真原型 返回需求看板

1. 业务说明

1. 本功能位于 Hk-Gw 官网首页顶部的导航栏，在“最新公告”左侧新增了“联系我们”入口。

2. 官网引流留资逻辑：为了捕捉官网的散客流量，点击该按钮后会弹出【试用账户申请】表单。

3. 收集到的数据将自动进入 CRM-HK 后台的“留资列表”中，供市场人员跟进分配。

2. 【留下资料】留资弹窗交互说明

1. 点击顶部红色的“联系我们”按钮触发弹窗。

2. 弹窗 UI 样式与 CRM-HK 注册页的留资弹窗保持绝对一致（深色Header、左灰右白表单结构）。

3. 弹窗文案提示：“信息提交后，我们的顾问会在2个工作日内与您联系”。

4. 成功提交后关闭当前弹窗，弹出定制 UI 提示框：“您的资料已提交，请注意邮箱信息”。

字段名称 是否必填 限制规则 逻辑说明
姓名 是 无特殊限制 标准文本输入框。左侧 Label 带红色星号。
联系电话 是 仅限数字 标准文本输入框。左侧 Label 带红色星号。
电子邮箱 是 标准邮箱格式 失去焦点时校验格式。左侧 Label 带红色星号。
咨询内容 否 下拉单选框 选项包含：“请选择”（默认）、“政策了解”、“开户咨询”、“其他”。
验证码 是 4位图形验证码 图形验证码放置在输入框右侧内部，点击可刷新。左侧 Label 带红色星号。
取消/提交按钮 - - 点击【提交】后校验必填项，成功后当前弹窗自动关闭，并弹出 UI 提示：“您的资料已提交，请注意邮箱信息”。数据同步至后台留资池。
