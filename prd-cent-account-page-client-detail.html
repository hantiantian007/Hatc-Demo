【页面 PRD】客户详情

查看原型 返回看板
本文档仅描述客户详情页面因接入美分账户而新增或调整的需求。
1. 页面目标
目标在单客户详情中清晰展示其标准账户与美分账户并存状态，以及不同账号的账户属性和币种单位。
涉及页面admin-client-detail.html
2. 新增/调整需求
需求项说明
账户类型展示客户详情需支持展示 标准账户 + 美分账户 的混合状态。
MT账号数量展示构成MT账号数量需展示为总数 + 构成，例如：3（标准 2 / 美分 1）。
账号属性区分账号列表中需区分 标准账户[交易] / 标准账户[佣金] / 美分账户[交易]。
资金信息调整累计入金、累计出金、净入金等信息保留数值本身，不增加“USD 汇总”提示文案。
美分金额展示美分账户行内金额只展示 USC/美分 原始金额，不展示“折合 USD”。
交易手数分开展示客户详情中的累计交易手数不再展示为单一总值，需拆分为 累计标准交易手数 与 累计美分交易手数。
账号列表补手数口径账号列表新增 手数口径 列，标准账户显示 标准手，美分账户显示 美分手。
3. 数据口径
客户级信息顶部资金信息为客户级汇总视图。
账号级信息账号列表是单 MT 账号视图，标准账户显示 USD/美元，美分账户显示 USC/美分。
交易手数口径客户级交易手数需按 标准手 与 美分手 分开统计和展示，两类手数不可融合为单一总手数。
4. 测试重点
1. 账户类型、MT账号数量构成、账号属性是否展示正确。
2. 美分账户行内金额是否仅展示 USC/美分，无折合 USD 文案。
3. 资金信息区是否已移除“USD 汇总”提示。
4. 累计标准交易手数和累计美分交易手数是否已分开展示，未被合并统计。
5. 账号列表中的手数口径列是否与账户类型匹配。
