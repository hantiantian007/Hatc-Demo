需求规格说明书 (PRD)

C端商品列表页 (client-product-list.html)

2026-07-01 产品部 V2.2.0
1. 页面加载与数据来源
UI 元素 数据来源与过滤条件 排列展示与处理逻辑
列表请求机制 来源：后端商品列表接口。
条件：仅拉取状态为“已上架”的商品。		 隐藏所有“已下架”及未到生效时间的“定时上架”商品。
排序规则：按后台配置的排序值（若有）升序排列，其次按上架时间倒序排列。
列表展示容器 网格布局 (Grid) 采用响应式网格布局，大屏 (lg) 一行展示 3~4 个卡片，中屏 (md) 一行 2 个，小屏 (sm) 一行 1 个。
卡片高度需保持一致（利用 flex-1 撑开内部描述区域），确保视觉整齐。
2. 商品卡片字段展示规范
字段名称 数据来源与计算方式 UI 视觉与排版逻辑
封面图与标签 来源：商品基础配置（列表展示图、商品类型）。 排列：顶部 160px 高度容器展示封面图（或带图标的渐变背景）。
标签：在左上角绝对定位显示“虚拟商品”或“实体商品”标签（黑色半透明背景）。
商品名称与简介 来源：商品基础文本配置。 标题：单行加粗文本，超出省略。
简介：采用 line-clamp-2（最多两行），超出部分显示省略号，文字颜色使用次级灰（text-gray-500）。
支付方式 来源：全局固定规则。 展示：“ 余额购买”灰色小标签，表明当前平台仅支持 CRM 钱包余额扣减。
库存展示 来源：该商品下所有套餐库存的汇总总和。 正常状态：显示在金额上方的小字，如“金额 (库存: 99)”。
售罄状态：当总库存为 0 时，文本变更为红色加粗的“金额 (库存: 0 售罄)”。
金额展示 来源：商品关联的所有套餐配置。
计算：遍历所有套餐，取出价格最低的套餐金额。 		单套餐：直接展示金额（如 $800.00）。
多套餐：金额后增加“起”字标识（如 $5,000.00 起）。
售罄状态：金额数字增加中划线（line-through）并置灰。
3. 交互跳转与逻辑
操作触发 动作类型 交互流转与跳转参数
点击卡片 / 查看详情 页面跳转 (正常库存) 交互：点击整张卡片区域或右下角的“查看详情”按钮，页面跳转至 product-detail.html。
传参：URL 必须携带 ?id=商品唯一ID 参数。
点击卡片 (已售罄) 操作阻断 交互：
1. 底部按钮文本变为“已售罄”，样式置灰并禁用 (disabled, cursor-not-allowed)。
2. 卡片整体不可点击跳转，鼠标悬浮不呈现指针手型 (cursor-pointer)。
4. 逆向与异常流转处理
异常场景分类 触发条件与场景描述 前端处理方案与交互阻断
空数据状态 后端返回的商品列表为空（例如所有商品均已下架）。 空状态占位：隐藏商品网格容器，居中展示插画及提示文案：“暂无可购买的商品，敬请期待”。避免页面出现突兀的白屏。
网络异常/接口超时 进入页面时拉取列表数据失败。 异常降级：结束骨架屏，展示网络错误提示块，并提供“重新加载”按钮供用户手动重试。
价格异常展示 若由于后端配置错误，拉取到的最低套餐价格为空或负数。 前端兜底：默认显示为“价格配置中”，并暂时阻断详情页的跳转，防止产生异常订单。
