新增销售页面需求说明

文档版本：v1.3 | 关联版本：v1.1.0

核心说明

本需求精确描述新增销售页面的所有字段交互、下拉选项、前端联动逻辑及数据计算规则。严格与原型字段保持100%一致，不包含任何业务数据埋点需求。

1. 基础配置

字段名称组件类型下拉内容/限制交互联动与业务逻辑
销售名称带联想输入框 / 保持现有内容不变，支持输入销售名称或邮箱进行检索选择。
是否享受返佣下拉单选框 ["请选择", "是", "否"] 选择“是”后，该销售则同时享受另外一套返佣规则；选择“否”则不享受另一套返佣规则。

2. 交易奖励配置

字段名称组件类型下拉内容/限制交互联动与业务逻辑
是否开启交易奖励下拉单选框 ["请选择", "是", "否"]
  • 选择“否”时，下方不显示内容。
  • 选择“是”时，则显示下方的配置项。
奖励计算方式单选Radio ["统一计算", "规则计算"]
  • 统一计算：则在下方列表内选择并输入对应数值；点击“编辑”按钮则可编辑，编辑后点击“保存”按钮则对数据进行保存。输入框内只可输入数字，小数点后保留两位小数。
  • 规则计算：选择后，下方显示配置按钮，点击后弹出配置弹窗。
交易持仓间隔文本输入框 只可输入数字，小数点后保留两位小数。 用于限制有效订单的持仓时间，输入框后带固定文案“秒”。
交易奖励结算周期下拉单选框 ["请选择", "实时", "每日", "每周", "每月", "每季度", "每年"] 计算规则： 每周、每月、每季度、每年，均为该周期最后一天的 23:59:59 进行计算。

3. 净入金奖励配置

字段名称组件类型下拉内容/限制交互联动与业务逻辑
是否开启净入金奖励下拉单选框 ["请选择", "是", "否"]
  • 选择“否”时，下方不显示内容。
  • 选择“是”时，则显示下方的配置项。
是否计算历史净入金下拉单选框 ["请选择", "是", "否"]
  • 选择“是”后，需要计算历史的净入金情况。
  • 选择“否”后，不需要计算历史的净入金情况。
  • 【独立显示】下方的“计算开始时间”为常驻显示，不与其进行联动隐藏，由配置人员按需直接选择。
计算开始时间单选Radio ["注册时间", "规则启动时间"] 计算开始时间是指历史净入金的计算时间。
  • 注册时间：从用户（非销售）注册时间开始计算净入金。
  • 规则启动时间：根据创建这个销售规则的时间开始计算用户的净入金。
交易量规则下拉单选框 ["请选择", "单个用户", "所有用户合计计算", "按分组/代理计算"]
  • 选择按分组/代理计算时：右侧显示配置按钮，点击后弹出弹窗。
  • 选择单个用户即：每当一个用户满足这个交易手数条件时，就达成一个条件。同时展示交易手数输入框。
  • 选择所有用户合计计算即：为所有用户一共达到这个条件后，这个销售就达成交易手数的条件。同时展示交易手数输入框。
奖励计算方式单选Radio ["统一计算", "规则计算"]
  • 统一计算：下方需要填写【净入金值】、【净入金奖励比例】。比例输入数字，小数点保留后2位；净入金值输入数字，小数点保留后2位。
  • 规则计算：显示配置按钮，点击弹出弹窗配置。
净入金值逻辑：
当用户满足净入金值后，销售才可以享受奖励。
奖励计算方式 = 净入金 * 净入金奖励比例
净入金奖励周期下拉单选框 ["请选择", "每月", "每季度", "每年"] 逻辑与交易奖励的结算周期计算逻辑一致（均为最后一天的 23:59:59 计算）。

4. 异常、边界约束与计算规则

  • 表单所有数值输入框必须强制拦截非数字及非小数点字符，实时格式化保留两位小数。
  • 表单提交保存时，若必填项为空，需阻断提交。
  • 四舍五入规则：系统中所有的奖励金额计算最终结果，如出现多位小数，均统一采用 四舍五入 规则保留两位小数。
  • 净入金奖励发放原则：满足净入金门槛后，实行 全额奖励（即：总净入金 * 比例），而非超出部分奖励。

4.1 历史净入金“负数结转清零”逻辑说明

核心原则：净入金奖励为负数时，当期不产生奖励；但负数净入金会向后结转累计，直到累计净入金转为正数时才予以发放当期奖励；若某期累计净入金为正数（已发放奖励），则该正数不向后结转，下一期重新从零开始计算当期净入金。

业务计算推演示例：

  • 【1月】：当月净入金为 负数 -> 结果为负数，1月无奖励。
  • 【2月】：计算方式为 1月 + 2月，若结果仍为 负数 -> 2月无奖励。
  • 【3月】：计算方式为 1月 + 2月 + 3月，若结果为 正数 -> 3月予以发放奖励。
  • 【4月】：由于3月已为正数（已结清），计算方式仅看 4月当月。若结果为 负数 -> 4月无奖励。若结果为 正数 -> 4月予以奖励。
  • 【5月】：若4月为负数，计算方式为 4月 + 5月，依此类推（负无正有）；若4月为正数，则5月仅计算 5月当月。
  • 【6月】：若5月为负数（且4月为正数），计算方式为 5月 + 6月，依此类推。
