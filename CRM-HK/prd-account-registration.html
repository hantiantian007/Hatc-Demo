【需求文档】CRM-HK 港版注册

返回需求看板

1. 需求背景

本需求属于已完成的 HK 开户/注册流程上的新增逻辑，不重做整套港版注册流程，只新增“根据不同邀请链接，动态判断投资者类型是否展示、是否可改、是否进入专业投资者问卷”的规则，并将最终投资者类型自动归入对应客户分组。

项 说明 口径
需求名称 港版注册 CRM-HK 独立开户/注册向导的增量逻辑调整。
影响范围 CRM-HK 注册入口、投资者类型页、专业投资者问卷、注册入库、后台审核回显、客户分组归属。 仅 HK 版本生效，Group 端不受影响。
目标 根据邀请链接控制注册路径。 减少错误开户路径，确保不同开户链接导入的客户走正确的投资者类型流程。

2. 核心原则

原则 定义 说明
链接驱动 注册页加载后先识别邀请链接类型，再决定后续页面路径。 不允许前端脱离链接自行猜测流程。
类型受控 当邀请链接已明确投资者类型时，用户不能修改类型。 避免代理渠道导流后用户自行切换到不匹配的开户类型。
最少展示 只有在业务上确实需要用户选择或确认时，才展示投资者类型页面。 能隐藏就隐藏，减少用户理解负担。
自动归组 注册提交成功后，系统按最终投资者类型自动写入对应分组。 不依赖人工在后台二次维护。

3. 邀请链接规则总表

链接来源/类型 是否展示投资者类型 是否允许修改类型 是否进入问卷 最终投资者类型
公司账户分享链接 展示 允许用户自行选择 按所选类型决定 以用户所选结果为准
代理分享一般投资者邀请链接 不展示 不允许修改 不进入专业投资者问卷 固定为一般投资者
代理分享专业投资者邀请链接 展示页面 不允许修改 必须进入专业投资者问卷 固定为专业投资者
代理分享标准邀请链接 不展示 不允许修改 不进入专业投资者问卷 为空

4. 页面展示与交互规则

模块 展示与交互规则 备注
投资者类型选择页 仅在“公司账户分享链接”场景下展示为可选页面。 用户必须选择后才能进入下一步。
专业投资者确认页 在“代理专业投资者邀请链接”场景展示，但页面中的投资者类型不可修改。 页面重点是说明当前开户链接只支持专业投资者，并引导进入问卷。
专业投资者问卷 仅专业投资者路径进入。 一般投资者与默认标准链接不展示该问卷。
开户资料页 沿用现有 HK 开户资料表单。 本需求不改资料字段，仅新增邀请链接驱动的展示与归组逻辑。

5. 数据字段建议

字段 说明 建议值 / 口径
invite_link_type 邀请链接类型。 company / agent_retail / agent_professional / agent_standard
investor_type 最终投资者类型。 retail / professional / 空
investor_type_source 投资者类型来源。 user_selected / link_fixed / 空
need_investor_type_page 是否展示投资者类型页面。 true / false
need_professional_questionnaire 是否进入专业投资者问卷。 true / false
customer_group 客户分组。 一般投资者自动归属一般投资者分组；专业投资者自动归属专业投资者分组；标准邀请链接自动归属代理的分组。

6. 自动归组规则

最终投资者类型 自动归组 触发时机
一般投资者 自动归属一般投资者分组 注册提交成功并入库时自动写入
专业投资者 自动归属专业投资者分组 注册提交成功并入库时自动写入
投资者类型为空（标准邀请链接） 自动归属代理的分组 注册提交成功并入库时自动写入

7. 后台审核与回显联动

模块 联动要求 说明
审核详情页 回显投资者类型、投资者类型来源、是否完成专业投资者问卷。 若为标准邀请链接，则投资者类型允许为空，并需回显归属代理分组。
登录控制 延续现有 HK 审核强控逻辑。 本需求不改变“审核通过后才能登录”的既有规则。
新老流程切换 继续支持后台开关切换。 本需求属于新流程上的增强逻辑，旧流程是否启用由后台配置决定。

8. 边界规则

场景 规则 说明
邀请链接缺失或非法 按公司账户分享链接处理。 展示投资者类型页面，由用户自行选择，避免因链接异常导致无法注册。
标准邀请链接未配置默认类型 投资者类型保持为空，直接归属代理的分组。 标准邀请链接不再强制映射到一般或专业投资者类型。
专业投资者链接下尝试改类型 前端不可编辑，后端再次校验为专业投资者。 避免前端篡改。
公司账户分享链接下选择专业投资者 必须完成专业投资者问卷后才允许提交。 问卷未完成时不可进入最终提交状态。

9. 验收标准

用例 操作 预期结果
公司账户链接 用户通过公司账户分享链接进入注册页。 展示投资者类型页面，用户可自行选择；若选择专业投资者，则进入专业投资者问卷。
代理一般投资者链接 用户通过代理分享的一般投资者邀请链接进入。 不展示投资者类型页面；系统固定为一般投资者；直接进入一般投资者开户路径。
代理专业投资者链接 用户通过代理分享的专业投资者邀请链接进入。 展示专业投资者确认页，但不能改类型；必须完成专业投资者问卷。
代理标准邀请链接 用户通过代理标准邀请链接进入。 不展示投资者类型页面；最终投资者类型为空；注册成功后自动归属代理的分组。
自动归组 用户提交注册成功。 系统根据最终投资者类型或标准邀请链接规则自动归入对应分组，后台审核页可正确回显。
