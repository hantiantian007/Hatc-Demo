1. 业务说明

1. 本页面为 CRM-HK 独立对外的 C 端个人开户申请页面（繁体中文环境），采用多步骤（Wizard）表单引导模式。

2. 核心流程分为 4 步：個人資料 -> 銀行資料 -> 上傳證明文件 -> 投資者問卷。

3. 前端实现必填项强校验：只有当前步骤所有带红色星号（*）的必填项校验通过，才允许点击“下一步”。

2. 步骤 1：個人資料 (登錄信息與基本資料)
字段名称 是否必填 字段类型/选项 交互逻辑与说明
電郵地址 是 文本输入 (Email) 系统唯一登录凭证，需校验标准邮箱格式。
登錄密碼 / 確認密碼 是 密码输入 需校验两次输入的密码是否完全一致。
推薦碼 是 文本输入 必填项，强制绑定上级代理关系。
下方附带提示：無邀請碼，請點擊此處：申請賬號
点击弹窗交互：点击“申請賬號”弹出【留下資料】留资表单，收集散客姓名、电话等意向。
提交后关闭当前弹窗，弹出定制 UI 提示框：“您的資料已提交，請注意郵箱信息”，同步至后台留资列表。
國籍 是 下拉选择 选项包含：中國、中國香港、中國台灣、其他。
客戶姓名 是 文本输入 真实姓名。此字段值将在步骤2中自动带入“開戶人名稱”中。
性別 是 下拉选择 选项包含：-請選擇-、保密、男士、女士。
證件號碼 / 確認 是 文本输入 需校验两次输入的证件号码是否完全一致。
居住地址 是 单选 + 文本域 先选择“居住地址是否與證件上顯示的住址相同？”（是/否）。不论选哪项，都必须在下方多行文本框内填写详细地址。
常用電話 是 下拉选择 + 文本输入 前置区号选择（86/852/886），后置电话号码输入（需为数字）。
微信 / QQ號碼 否 文本输入 选填的辅助联系方式。
3. 步骤 2：銀行資料
字段名称 是否必填 字段类型/选项 交互逻辑与说明
開戶人名稱 是 文本展示 (Readonly) 不可编辑，灰色背景。系统自动带入步骤 1 中填写的“客戶姓名”。
銀行賬號 / 確認 是 文本输入 需校验两次输入的银行卡号是否完全一致。下方附带提示：開戶名必須為客戶本人。
開戶行名稱 是 下拉选择 仅支持香港地区银行。选项包含：香港上海匯豐銀行 (HSBC)、中國銀行(香港) (BOC HK)、渣打銀行(香港) (Standard Chartered)、恒生銀行 (Hang Seng)、東亞銀行 (Hang Seng)、星展銀行(香港) (DBS HK)、其他香港本地銀行。
開戶行地區 是 联动下拉选择 由于仅支持香港地区，左侧固定且置灰不可更改（值为“香港特別行政區”），右侧下拉选择分區（香港島、九龍、新界）。
分行與支行 是 多行文本域 要求用户详细填写支行名称以便处理存取款。
4. 步骤 3：上傳證明文件
字段名称 是否必填 字段类型/选项 交互逻辑与说明
證件正面照片 是 文件上传 支持 .jpg/.jpeg/.png/.gif，限制最大 3M。前端需提供点击选择文件的交互区域。
證件背面照片 是 文件上传 要求同上。与正面照片共同用于核实客户身份。
銀行卡正面照片 是 文件上传 要求同上。用于后台审核客户的资金出入合规性。
5. 步骤 4：投資者問卷
字段名称 是否必填 字段类型/选项 交互逻辑与说明
客戶類別 是 单选框 选项：“一般投資者”（默认）与“專業投資者”。
联动逻辑：当选择“專業投資者”时，下方自动展开【請明確投資風險和後果】的 4 项专业资质确认复选框组。选择“一般投資者”时则隐藏。
专业资质选项
(仅专业投资者)		 否 复选框组 包含 4 大项确认，其中第 1 项下属 3 个子资质复选框（如：金融學士、CFA/CFP、合資格律師）。用户可多选。
提交開戶申請 - 按钮 到达第 4 步时，“下一步”按钮变为“提交開戶申請”。
点击提交后，弹出全屏的【成功提交彈窗】，提示“您的資料已經提交，請注意郵箱信息”。
6. 提交成功后动作

1. 弹窗内提供两个按钮流向：

- 查看審核進度：跳转至极简的审核进度查询页面（check-status.html）。

- 返回首頁：直接跳转回登录或系统入口首页。
