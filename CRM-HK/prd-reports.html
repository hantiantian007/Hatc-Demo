风控与运营报表 PRD (盈亏、净值、持仓)

业务模式：Mode B (直连 MT5)
目标用户：风控、市场、运营人员
更新日期：2026-07-02
状态：已评审
设计原则红线： 严格遵循“做减法”原则，取消所有冗余的配置型需求；在同页面内通过视图模式完成数据状态的切换，避免页面跳跃。

全局交互与数据规范

  • 数据模式切换 (Mode Switcher)：报表统一支持在【实时数据】与【历史快照】间切换。
    • 实时数据模式下：时间选择器置灰不可用。展示文案变更为 实时统计 (本月1日至当前)。系统强制按本月维度聚合流水数据。
    • 历史快照模式下：必须选择时间范围（支持到天）。
  • 左右联动架构 (Tree & Grid)：放弃传统的复杂下拉表单筛选，采用左右分栏联动设计。
    • 左侧关系树：展示完整的代理/直客层级架构，支持展开/折叠。
    • 右侧汇总卡片：点击左侧任意节点后，上方汇总卡片动态变更为“该节点及其所有下级（伞下）”的资金汇总数据。
    • 右侧数据列表：表格取消嵌套展开，改为扁平化列表。第一行固定展示当前选中节点，下方列表展示该节点的直属下级。
  • 样式约束：数据表格的所有内容强制不换行（whitespace-nowrap），保持视觉整齐；货币和数值型数据统一右对齐，保留两位小数。

1. 盈亏报表 (P/L Report)

查看原型

层级结构

顶级代理 (IB) 子代理 (Sub-IB) 直属客户 (Client)

核心字段与计算公式

字段名称 数据来源与定义 实时获取与快照可行性评估
净值 MT5 账户核心指标。账户当前的清算价值（结余+信用+浮动盈亏）。 实时：极易。直接通过 MT5 API 读取 Account Summary。
快照：极易。系统每日 EOD (End of Day) 定时任务记录快照即可。
结余 MT5 账户核心指标。客户账户的实际现金余额（不含信用和浮动盈亏）。 实时：极易。同上。
快照：极易。同上。
信用 MT5 账户核心指标。账户中的赠金/信用额度。 实时：极易。同上。
快照：极易。同上。
浮动盈亏 MT5 实时持仓。该层级所有未平仓订单的实时盈亏总和。 实时：需通过 API 遍历该账号下所有 Open Positions 并累加盈亏，数据量大时有一定性能开销。
快照：易。按天汇总持仓快照即可。
平仓盈亏 MT5 历史订单。该层级所有已平仓订单的盈亏总和。 实时：性能开销大。建议采用 MT5 数据流订阅 + 本地增量聚合（如 Redis 缓存），严禁在查询接口中直接向 MT5 发起大跨度聚合请求。
快照：易。按天计算增量并落库。
手续费 MT5 历史订单。交易产生的手续费总和。 实时：同上，需做增量缓存架构。
快照：易。
佣金 MT5 历史订单。交易产生的佣金总和。 实时：同上，需做增量缓存架构。
快照：易。
过夜利息 MT5 订单。隔夜持仓产生的利息（含已平仓和未平仓）。 实时：性能开销最大。未平仓部分查实时持仓，已平仓部分查本地增量缓存聚合。
快照：易。

2. 净值报表 (Equity Report)

查看原型

业务目标：核心风控页面，主要用于实时监控客户的账户健康度，及时发现可能引发穿仓风险的账户。

核心字段与计算公式

字段名称 定义与公式 (严格遵循 MT5 标准)
余额 (Balance) 客户账户的实际现金余额（不含赠金和未平仓盈亏）。
净值 (Equity) 余额 + 赠金 + 浮动盈亏。账户当前的清算价值。
预付款 (Margin) (交易手数 × 合约规模 × 当前价格) / 杠杆。当前持仓被冻结的保证金。
预付款比例 (Margin Level) (净值 / 预付款) × 100%。衡量账户爆仓风险的唯一核心指标。

预警交互逻辑

  • 当任意直客账户的 预付款比例 < 150% 时，该数据行整行采用浅红色背景（bg-red-50）高亮。
  • 高风险行内的预付款比例数值需用醒目的红色区块（如红底白字）突出显示。
  • 代理节点不计算预付款比例（因代理本身不交易），代理行的预付款比例列显示为 -。

3. 持仓报表 (Position Report)

查看原型

业务目标：监控各交易品种在平台内的整体多空敞口方向，防止某一品种单边敞口过大带来的系统性赔付风险。

特殊层级结构 (逆向思维)

交易品种 (Symbol, 如 XAUUSD) 代理 (IB) 直属客户 (Client)

核心字段与计算公式

字段名称 定义与公式
多头手数 (Buy Lots) 该节点下所有 Buy 方向未平仓订单的总手数。
空头手数 (Sell Lots) 该节点下所有 Sell 方向未平仓订单的总手数。
净敞口手数 (Net Lots) 多头手数 - 空头手数。正数代表平台整体面临价格下跌的赔付风险，负数代表面临价格上涨的赔付风险。
净敞口盈亏 (Net P/L) 多头总浮盈 + 空头总浮盈。
