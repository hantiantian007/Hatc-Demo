1. 改动点 1：当前汇率提示语（当前命中通道）

1.1 业务说明（为什么需要这个提示）

平台人民币支付方式同时对接多个第三方渠道（QuickPay-WeChat / QuickPay-Allpay / QuickPay-CNY / alpay / GlobalPay-CNY 等）。针对同一币种（CNY），系统按以下规则为客户端入金择优：

  • 择优规则：同币种多个启用通道，按汇率最高优先，取第一条作为当前命中通道。
  • 降级兜底：命中通道调用失败时，系统按汇率排序自动顺推下一个启用通道。
  • 禁用通道不参与排序。

1.2 命中通道的计算规则（后端/前端统一口径）

# CNY 当前命中通道
候选 = 所有 (币种 == CNY) AND (状态 == 启用) 的通道
若 len(候选) == 0：
    不展示"当前命中通道"提示卡（整卡隐藏）
否则：
    按 汇率 DESC 排序（保留 2 位小数，6.88 > 0 > - ）
    取 TOP 1 作为"命中通道"，在卡片展示：币种 + 简称 + 汇率
# 其他币种（HKD、USDT）暂不展示命中提示，保留后续迭代口。

显示案例（正常）

当前命中通道   CNY · alpay   汇率 6.88

极端情况 A

CNY 通道全部禁用 → 提示卡整卡隐藏（不显示"无命中"等字样，保持界面简洁）。

极端情况 B

多个通道汇率相同（同为 6.88）→ 取编号较大 / 最近创建者，建议后端按"更新时间 DESC"作为二级排序键。

2. 改动点 2：通道来源类型

2.1 列位置与表头

  • 表头位置：状态列的右侧、操作列的左侧，插入"通道来源"一列。
  • 表头文案：通道来源。居中对齐。
  • 所有行均需填值，不允许为空。

2.2 枚举值与 Tag 样式

枚举值 视觉样式 业务含义 典型通道示例
接口查询 接口查询 通道状态、汇率等关键字段由第三方支付接口实时回传/拉取，本页编辑不生效，或仅作展示用。 QuickPay 系列、CryptoLink 全链、GlobalPay-CNY
页面配置 页面配置 通道参数完全由本页面录入，保存后立即生效（或进入审核流）。汇率、状态、限额均为页面静态配置。 USDT-TRC20/ERC20/BEP20（链上地址）、Pcard、alpay

3. 验收标准（AC）

# 场景 验收条件
AC-1 命中提示展示 当存在 ≥1 个 CNY 启用通道时，筛选条件行内展示"当前命中通道 CNY · XXX 汇率 X.XX"，内容与列表该通道实际汇率一致（精确 2 位小数）。
AC-2 命中提示隐藏 把所有 CNY 通道切为禁用后，命中提示卡整体隐藏（页面不残留空容器或"-"占位）。
AC-3 通道来源列完整 所有行的通道来源列必为"接口查询"或"页面配置"之一，样式与本 PRD 色板一致。无空值、无错位。
