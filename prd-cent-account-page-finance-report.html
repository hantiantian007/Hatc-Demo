【页面 PRD】财务报表

查看原型 返回看板
本文档仅描述财务报表页面因接入美分账户而新增或调整的需求，不重复描述原有标准账户财务报表能力。
1. 页面目标
目标在财务报表中支持标准账户与美分账户混合查询，确保搜索、列表、展开明细、汇总统计与导出在美分场景下口径一致。
涉及页面admin-report-finance-cent-account.html
2. 新增/调整需求
需求项说明
新增账户类型筛选搜索区新增 账户类型，支持全部、标准账户、美分账户筛选。
新增手数口径筛选搜索区新增 手数口径，支持全部、标准手、美分手筛选，用于按手数体系独立查询财务记录。
新增账户类型列列表中新增 账户类型 列，明确当前财务记录属于标准账户还是美分账户。
新增手数口径列列表中新增 手数口径 列，明确当前交易手数属于 标准手 还是 美分手。
汇总金额统一按 USD汇总区中的 平仓盈亏 / 库存费 / 手续费 统一按 USD 口径展示，便于混合账户汇总。
交易手数分开统计汇总区不再展示单一 交易手数总计，改为分别展示 标准账户交易手数 与 美分账户交易手数；两类手数不可合并统计。
美分明细补充原始金额美分账户记录展开后，需要补充展示原始 USC/美分 口径的库存费与平仓盈亏。
原型 Demo 数据脱敏原型中的客户姓名、邮箱和 MT 账号需使用匿名示例数据，不使用真实人员名称和真实 MT 账号。
导出口径与页面一致报表导出字段需与页面当前筛选结果一致，涉及金额字段按页面口径输出，混合账户场景下汇总字段统一为 USD。
3. 数据口径
列表维度本页按单笔财务记录展示，允许标准账户与美分账户混排。
汇总口径交易手数按账户类型分开累加，分别展示 标准手 与 美分手；平仓盈亏、库存费、手续费统一按 USD 折算后汇总展示。
明细口径标准账户展开明细按 USD/美元 展示；美分账户展开明细同时展示折算后的 USD 值和原始 USC/美分 值。
价格字段口径开仓价格、平仓价格 属于交易品种成交价，不区分标准账户或美分账户单位，页面保持原始成交价展示；如不同 MT5 分组存在点差差异，则直接展示该账户所属分组的真实成交价。
换算关系美分账户金额换算规则固定为 1 USD = 100 USC，页面展示仅保留结果，不额外增加解释文案。
4. 交互规则
筛选联动选择账户类型或手数口径后，列表、汇总统计和导出结果均需同步刷新。
展开行点击列表前置箭头后，在下方按字段逐行展开手续费、库存费、平仓盈亏和注释等补充信息。
页面精简不新增独立说明区块，仅在搜索、表格和展开明细中补充必要的美分识别信息。
5. 测试重点
1. 账户类型、手数口径筛选是否可正确筛出目标财务记录。
2. 汇总区中的标准账户交易手数和美分账户交易手数是否分开展示，未被合并统计。
3. 汇总区中的平仓盈亏、库存费、手续费是否统一按 USD 展示。
4. 美分账户展开明细是否能同时看到折算后的 USD 值和原始 USC 值。
5. 展开区是否保持下方逐行排列，不出现横向错位或换行异常。
6. 原型 Demo 数据是否已全部脱敏，不包含真实姓名、真实邮箱和真实 MT 账号。
